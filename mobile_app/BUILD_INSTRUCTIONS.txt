HOW TO BUILD THE ANDROID APK
============================

Prerequisites:
1. Python 3.8+ installed.
2. Flutter SDK installed (https://docs.flutter.dev/get-started/install/windows).
   - Add 'flutter/bin' to your PATH.
   - Run 'flutter doctor' to verify setup.
3. Android SDK (usually installed via Android Studio).
   - Ensure 'ANDROID_HOME' environment variable is set.
   - Install "Android SDK Command-line Tools" via Android Studio SDK Manager.

Build Steps:
1. Open a terminal (PowerShell or CMD).
2. Navigate to this folder:
   cd c:\Users\tobia\Documents\LeprendiX\LeprendiX\mobile_app

3. Install dependencies:
   pip install flet

4. Run the build command:
   flet build apk

The final APK will be located in: build/apk/app-release.apk
